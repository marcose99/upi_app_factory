# Project Charter — UPI Dispute Resolution Factory

Status: LOCAL_PRODUCTION_DISCIPLINED_FACTORY_PROTOTYPE

This project generates a mock-safe UPI failed transaction and dispute resolution case management application through a governed agentic software factory.

Non-negotiable boundaries:

- No real UPI/NPCI/bank/payment calls.
- No real customer data.
- No production credentials.
- No official compliance claim without evidence.
- All external systems are mocks unless explicitly approved.
- All mutating operations must produce audit events.
- All release readiness claims require validation evidence.
