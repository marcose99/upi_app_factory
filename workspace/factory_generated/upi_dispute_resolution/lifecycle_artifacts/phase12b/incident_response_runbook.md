# Incident Response Runbook

Incident examples:
- real customer data detected;
- live integration attempt detected;
- secret committed or logged;
- false compliance/certification claim detected;
- generated code weakens safety policy;
- RAG/source poisoning detected;
- remediation causes regression.

Response:
- stop generation/remediation;
- preserve logs and evidence;
- classify severity;
- isolate affected artifacts;
- revert or quarantine changes;
- run validators;
- update incident evidence;
- require human review before continuing.
