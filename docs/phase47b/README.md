# Phase 47B — Logical Canonical Product Identity

This phase canonicalizes the factory product and repository identity to
`upi_app_factory`, with the human-readable name **UPI App Factory**.

The generated application identity `upi_dispute_resolution` is preserved.
Physical checkout-path references are deferred to Phase 47C, and remote
repository references are deferred to Phase 47D. Temporary environment
compatibility is provided without making the legacy identity authoritative.

The project-only conversation label is removed from the current tracked tree.
No tag, release, deployment, remote rename, physical checkout rename, or
certification claim is authorized by this phase.
