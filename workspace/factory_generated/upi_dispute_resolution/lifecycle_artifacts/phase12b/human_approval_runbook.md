# Human Approval Runbook

Human approval is required for:
- git commit, tag, push;
- dependency installation;
- network access;
- destructive file operations;
- live integration changes;
- tool authorization expansion;
- security-policy weakening;
- regulatory claim wording;
- quality objective waiver.

Approval record must include:
- approval_id;
- approver;
- date/time IST;
- requested change;
- affected artifacts;
- risk explanation;
- approval/denial;
- conditions.
