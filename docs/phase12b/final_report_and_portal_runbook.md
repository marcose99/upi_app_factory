# Final Report and Human Validator Portal Runbook

The final report and HTML portal must contain:
- factory identity, tags, branches, and phase history;
- factory capabilities and limitations;
- agent orchestration and handoff flow;
- tool authorization policy;
- memory/RAG/context policy;
- UPI domain guardrails;
- architecture and design details;
- generated application capabilities;
- generated application architecture and data flow;
- test, validation, evaluation, and audit results;
- remediation cycles with before/after scores;
- unresolved risks and accepted limitations;
- no production/compliance/certification/live-payment claims.

Every major statement must map to evidence paths.
