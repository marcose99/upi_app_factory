# Phase 11A.2 Prompt — Realistic Mock Production-Grade Engineering Guardrails

Strengthen all relevant agent prompts so future generated applications are
realistic, high-volume capable, concurrent where applicable, observable, and
migration-ready while remaining strictly mock-only.

- strictly mock-only external dependencies

- high-volume synthetic test scenarios
- high availability, failover, and failback design
- production-quality observability discipline
- production deployment planning without production-ready claims
- fail-closed guardrails
- deterministic validation
- human approval for protected writes
