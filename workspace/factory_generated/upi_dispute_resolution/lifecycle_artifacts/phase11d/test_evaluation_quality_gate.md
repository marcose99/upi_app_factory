# Test and Evaluation Quality Gate

Mandatory test/evaluation coverage:
- unit tests
- integration tests
- domain scenario tests
- negative tests
- regression tests
- limited local load tests
- limited local stress tests
- security tests
- policy validation tests
- observability validation
- release-readiness validation
- architecture/HLD/LLD scorecards
- generated output quality evaluation
- risk acceptance records

Local load/stress boundaries:
- synthetic data only,
- single-machine local execution,
- bounded request volumes,
- no live external integrations,
- no production performance claims.
