# Human Validator HTML Audit Portal Contract

The generated application run must produce a final offline HTML page for human validators.

Required characteristics:
- offline and self-contained wherever possible;
- animated diagrams using inline SVG/CSS or bundled local assets;
- no network dependency;
- readable by a non-authoring reviewer;
- evidence-backed;
- traceability from claims to artifacts;
- no production/compliance/certification/live-payment claims.

Required sections:
- executive summary
- factory capabilities
- factory architecture
- agentic workflow
- tool authorization
- memory/RAG/context engineering
- prompt and policy inheritance
- guardrails and risk controls
- LLM metrics and cost summary
- validation/test/evaluation summary
- generated app capabilities
- generated app architecture
- generated app data flow
- UPI domain scenario coverage
- audit evidence manifest
- human validator checklist
- known gaps and limitations
