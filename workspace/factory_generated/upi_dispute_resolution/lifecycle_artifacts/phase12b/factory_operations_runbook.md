# Factory Operations Runbook

Purpose: operate the Agentic AI factory safely, repeatably, and auditably.

Daily/Run operations:
- verify clean branch state;
- verify active phase branch;
- verify validators;
- verify run logs use Asia/Kolkata timestamps;
- verify no live external ecosystem integration;
- verify LLM metrics, expense ledgers, tool ledgers, handoff ledgers, validation ledgers, and audit evidence are present when applicable.

Mandatory before generation:
- Phase 11C, Phase 11D, and Phase 12A baselines must be finalized;
- tool authorization must be deny-by-default;
- audit foundation must be available;
- quality objectives must be loaded;
- human approval policy must be active.

Stop immediately if:
- live payment, bank, PSP, NPCI, RBI, ODR, or customer infrastructure is requested;
- real customer data is introduced;
- regulatory compliance or certification is claimed;
- validators regress;
- remediation budget is exhausted.
